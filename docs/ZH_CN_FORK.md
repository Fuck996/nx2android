# NX2Android 中文维护分支

这是面向简体中文用户的派生分支。上游为 [shirai91/nx2android](https://github.com/shirai91/nx2android)。本分支沿用上游的 MIT 许可证和各第三方组件的独立许可证；没有修改游戏内容，不随项目分发游戏、固件、密钥、游戏安装包或数据包。

## 分支约定

- `main` 只同步上游，不合入中文分支的补丁。
- `zh-cn/windows` 从上游提交派生，保留桌面翻译、安卓版移植菜单、游戏共享字体、依赖处理等各自独立的提交。中文功能的配置和资源尽量与上游逻辑分离。
- 初始上游基线：[581ca540f7b2214d47aee1e9be6156fc36809426](https://github.com/shirai91/nx2android/commit/581ca540f7b2214d47aee1e9be6156fc36809426)。

### 在 GitHub 上同步

1. 在 fork 的 `main` 上，用 **Sync fork → Update branch** 同步上游。若页面显示冲突或分支已分歧，先查看差异，不要丢弃提交。
2. 在 **这个 fork 内** 建合并请求：base 选 `zh-cn/windows`，compare 选 `main`。两边都应显示为这个 fork，不要选到上游仓库。
3. 核对差异和测试结果，用 **Create a merge commit** 合入。不要用 squash 或强推替代上游历史；如果有冲突，在临时分支解决并测试后再合入。
4. `main` 始终是只跟上游的分支。不要把中文分支反向合进 `main`。单独检视中文改动可用 [比较页](https://github.com/Fuck996/nx2android/compare/main...zh-cn/windows)，其范围以共同祖先为准。

## 《三国志14 威力加强版》验证范围

本分支继承了 [上游适配](../nxnative/dm/games/0100CD4012DCA000/README.md)：Switch 本体 Title ID `0100CD4012DCA000`、更新 `1.1.1`（`v786432`），配合追加内容编号 `49`（威力加强版）。优先使用各自独立的本体、更新、DLC 文件。上游在骁龙 8 Elite / Adreno 830 上报告 30 FPS；不能据此宣称本分支已在 Pocket FIT Elite 实机验证，也不保证其他区版或更新版本兼容。

## 发布前验收

- Windows：验证启动、移植/依赖/游戏/存档等页面、文件选择、错误提示；分别测试有合适工具链和缺少工具链的情况。
- Android：验证移植工具的暂停菜单、手柄设置、FPS 样式、布局编辑及存档提示。移植菜单的语言与游戏原有的文本语言分开验证。
- 使用自备且有权使用的游戏文件做设备测试。一个 APK 成功生成不等于特定游戏已能玩，也不能证明掉帧、字体或长时间运行没有问题。
- 保留上游和第三方的许可证、原始归属及支持范围。仅发布工具或其允许分发的依赖，不把个人游戏文件、密钥、存档或设备路径提交到 GitHub。
