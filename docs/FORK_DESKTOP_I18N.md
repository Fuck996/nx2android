# 桌面界面简体中文

桌面程序在简体中文系统（如 `zh-CN`）下自动使用简体中文；其他环境继续使用英语。
可在启动程序前将环境变量 `NX2A_UI_LANGUAGE` 设为 `zh-CN` 或 `en`，手动覆盖系统设置。
「移植」页的「游戏语言」只影响游戏自身，不受桌面程序语言影响。

桌面翻译集中在 `gui/locale_zh_cn.py`，运行时选择和子进程进度的翻译在 `gui/i18n.py`。
不要翻译命令参数、JSON 键、包名、路径或原始诊断日志。上游新增或修改的文案未翻译时回退为英语。
Qt 自带的标准对话框在可用时使用 Qt 的简体中文翻译；系统原生文件选择器遵循操作系统的语言。

合并上游后，检查 `gui/app.py`、`gui/runner.py` 的用户可见新文案。
调用 `tr('English text')` 时，在翻译表添加对应的简体中文；带变量的字符串用同样的命名占位符。
不要在上游 porter 协议里写翻译。运行 `python -m unittest discover -s tests -p 'test_gui_*.py'`。
