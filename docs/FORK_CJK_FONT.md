# 简体中文游戏字体

Windows 构建包自带开源静态 TrueType 字体 **NX2A CJK SC**，由 Noto Sans SC
2.004 生成，与暂停菜单使用的像素字体是两套资源。游戏语言实际为简体中文且
没有匹配的固件字体时，构建程序将此字体放进游戏数据包；无需手动找字体。
用户手动选的「系统字体」始终优先；字体不会改变游戏自身支持的语言或提供翻译。

制作 Windows 包时会从固定版本的 Noto CJK 上游拉取字体和授权文本、校验
SHA-256、生成 400 字重的静态 TTF，再将字体和 OFL 1.1 授权文本复制到构建包
内。仓库不含字体二进制。源码调试时可从仓库根目录执行
`python packaging/build_cjk_font.py build/game-fonts`；或在移植页手动提供自己
的简体中文 TTF。与原版一样，游戏、密钥及其固件仍由使用者自行提供。
